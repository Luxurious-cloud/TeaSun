## Headline conclusions

1. **No US-format label and no Nutrition Facts panel exist for any SKU.** This is new artwork creation,
   not adaptation.
2. **The nutritional values in the specifications are not usable as supplied** — 0.02 kcal/100 g for a
   dry tea product is not credible and appears to be a brewed-infusion figure in an "as sold" field.
3. **The "suitable for home composting" claim is the largest US exposure** in the current artwork and
   should be settled before it is repeated across the range.
4. **There is no US responsible party** on any pack — currently a UK entity and a Czech importer.
5. Only **one SKU** in the shared folder (Earl Grey 50 g) has both a specification and artwork.
6. The ~26-SKU range collapses into **five composition templates**, which is the right basis for volume
   pricing.
